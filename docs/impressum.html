Impressum

TrendZ ist ein privates, nicht-kommerzielles Hobbyprojekt.

Betrieben von Daniel, Schweiz.
Kontakt: über GitHub

Inhalte

TrendZ zeigt Titel, kurze Anrisstexte und Vorschaubilder aus öffentlichen RSS-Feeds und offiziellen Schnittstellen (APIs) und verlinkt immer auf die Originalquelle. Alle Rechte an diesen Inhalten liegen bei den jeweiligen Anbietern. Wer als Anbieter nicht aufgeführt werden möchte, kann sich über den oben genannten Kontakt melden; der Eintrag wird dann entfernt.

Datenschutz

TrendZ verwendet keine Cookies, kein Tracking und keine Analyse-Werkzeuge und speichert keine Daten über Besucherinnen und Besucher. Die Website wird von GitHub Pages bereitgestellt; GitHub verarbeitet dabei technisch notwendige Daten wie die IP-Adresse (Datenschutzerklärung von GitHub). Vorschaubilder werden direkt von den Servern der jeweiligen Quellen geladen.
